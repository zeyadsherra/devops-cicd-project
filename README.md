# Automated CI/CD Pipeline for Web Application

## Project Description
A simple web application used to demonstrate a basic DevOps CI/CD workflow with GitHub Actions.

## What the project demonstrates
- Git version control
- GitHub repository management
- Automated workflow execution
- Basic project validation
- GitHub Pages deployment can be enabled from repository settings

## Technologies
HTML, CSS, Git, GitHub, GitHub Actions, YAML

## How to run locally
Open `index.html` in a web browser.

## GitHub Pages
After pushing the project to GitHub:
1. Open the repository.
2. Go to Settings → Pages.
3. Select `Deploy from a branch`.
4. Select `main` and `/root`.
5. Save.

The preview URL will then be:
https://YOUR-GITHUB-USERNAME.github.io/devops-cicd-project/
